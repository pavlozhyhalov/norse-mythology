# ᚨ Нордична Міфологія — Повний довідник

Інтерактивний веб-довідник скандинавської (нордичної) міфології. Чистий HTML/CSS/JavaScript — жодних фреймворків, жодних залежностей. Розгортається напряму на **GitHub Pages**.

---

## 📂 Структура проєкту

```
norse-mythology/
├── index.html              # Головна сторінка (SPA)
├── css/
│   └── style.css           # Всі стилі (темна рунічна тема)
├── js/
│   └── main.js             # Навігація, рендеринг, пошук
├── data/                   # Дані окремими JS-файлами
│   ├── worlds.js           # 9 світів Іґґдрасіля
│   ├── aesir.js            # Боги-аси, богині, валькірії, норни
│   ├── vanir.js            # Боги-вани (Ньорд, Квасір)
│   ├── creatures.js        # Монстри і містичні істоти
│   ├── artifacts.js        # Священні артефакти
│   ├── runes.js            # 24 руни Старшого Футарку
│   ├── events.js           # Ключові події і міти
│   └── genealogy.js        # Генеалогія богів (SVG-дерево)
└── README.md
```

## 🚀 Запуск на GitHub Pages

1. **Fork** цього репозиторію
2. Перейди в **Settings → Pages**
3. Source: **Deploy from a branch** → `main` → `/ (root)`
4. Збережи — сайт доступний за `https://<username>.github.io/<repo>/`

### Локально
```bash
# Просто відкрий index.html у браузері
# АБО запусти локальний сервер:
python3 -m http.server 8000
# → http://localhost:8000
```

> ⚠️ Через `data-src` у `<script>` — відкривай через сервер, не через `file://`

## 📚 Першоджерела

### Старша Едда (Poetic Edda)
Збірка давньоісландських поем, записана бл. 1270 р. (Codex Regius, AM 748 I 4to):
- **Völuspá** — Пророцтво Провидиці (створення світу, Раґнарьок)
- **Hávamál** — Слова Високого (мудрість Одіна, відкриття рун)
- **Grímnismál** — Слова Ґрімніра (описи світів, чертогів)
- **Vafþrúðnismál** — Слова Вафтруднір (космологія)
- **Skírnismál** — Поїздка Скірніра (Фрейр і Ґерд)
- **Lokasenna** — Перебранка Локі
- **Þrymskviða** — Пісня про Трюма (Мйольнір)
- **Hymiskviða** — Пісня про Гюміра (рибалка Тора)
- **Baldrs draumar** — Сни Бальдра
- **Rígsþula** — Пісня про Ріґра (Геймдалль і людські стани)

### Молодша Едда (Prose Edda)
Написана Сноррі Стурлусоном бл. 1220 р.:
- **Gylfaginning** — Омана Ґюльфі (головне джерело нордичної космології)
- **Skáldskaparmál** — Мова поезії (міти про артефакти)
- **Háttatal** — Перелік розмірів

### Ynglinga saga
Частина Heimskringla Сноррі Стурлусона, бл. 1230 р.

## 🎨 Дизайн

- **Шрифти**: Cinzel Decorative, Cinzel, EB Garamond (Google Fonts)
- **Палітра**: Темна рунічна тема — золото `#c9a84c`, лід `#7db8d4`, вогонь `#c44b1a`
- **Без фреймворків**: чистий JS ES6+, CSS Custom Properties
- **SPA**: hash-роутинг (`#worlds`, `#gods`, `#runes` тощо)

## ⚠️ Примітки про достовірність

- Значення рун базуються на **рунічних поемах** (норвезькій, ісландській, англосакській) і сучасних дослідженнях (McKinnell, Flowers, Looijenga). Деталі **дискусійні** в науковій спільноті.
- Дата Раґнарьоку у першоджерелах не вказана — це **циклічна подія**, не одноразова.
- Деякі генеалогічні зв'язки **варіюються** між різними текстами Едд.
